# Repaso de Java (opcional)

Esta sección es opcional: repasa POO, herencia, polimorfismo, interfaces, colecciones y lambdas/streams en Java puro, sin infraestructura ni proyecto ejecutable — solo para afianzar la base antes de entrar en Spring Boot. Es un repaso denso, no un curso — asume que ya conoces estos temas y solo necesitas refrescarlos.

Si ya te sientes cómodo con ellos, puedes saltar directo a [Fundamentos](/docs/01-fundamentos).
